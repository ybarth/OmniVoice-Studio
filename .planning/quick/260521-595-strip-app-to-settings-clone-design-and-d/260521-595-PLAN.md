<objective>
Create a focused public-preview build of OmniVoice Studio: four tabs only
(Clone, Design, Drive, Settings), new anti-Babel visual identity, responsive
mobile/iPhone layout, and a one-command local/public dev runner.
</objective>

<design>
Brand: keep the local voice-studio purpose, but shift the visible identity to
"Concord Tower" / "Vox Tower" language: a tower of stacked voice bars that
converge into one bridge. Use a balanced palette rather than a single hue:
ink, ivory, lapis, copper, verdigris, and coral. Use existing packaged fonts
(`Source Serif 4`, `Inter`, `IBM Plex Mono`) and `lucide-react` icons; create
the logo in code/CSS so no external licensed assets are introduced.

App shell: make Clone the default mode. Remove Launchpad, Dub, Conversation,
Stories, Gallery, Transcriptions, Donate, Enterprise, Tools, Queue, Voice
Profile, the side history panel, and comparison/direction modals from the
active shell. Keep backend routes and files intact to avoid destabilizing the
local model/runtime surface.

Mobile: add deterministic device detection that marks the document with
`data-device`, `data-os`, and classes such as `device-iphone`. CSS uses these
attributes plus viewport breakpoints to switch from rail layout to a bottom
tab bar, honor safe-area insets, raise touch targets, and keep clone/design
forms readable on phones.

Public preview: Vite serves on all interfaces and proxies `/api` to the
backend. The frontend API client uses `/api` automatically on non-loopback web
hosts so phones reached through the tunnel call back to the host machine, not
their own `127.0.0.1`. A Node watchdog script starts backend, frontend, waits
for health, then runs `cloudflared tunnel --url http://127.0.0.1:3901`,
restarting any child that exits unexpectedly.
</design>
