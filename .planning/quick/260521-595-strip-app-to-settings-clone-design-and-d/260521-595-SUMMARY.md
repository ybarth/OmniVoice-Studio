# Quick Task 260521-595 Summary

## Result

Built a focused Vox Tower public preview that keeps only Clone, Design, Drive, and Settings in the active shell. The UI now uses a self-owned anti-Babel visual identity with a tower mark, mixed copper/lapis/verdigris/gold palette, and existing bundled fonts plus lucide icons.

## Implementation Notes

- Replaced the broad application router with a four-mode shell in `frontend/src/App.jsx`.
- Reduced the primary navigation to Clone, Design, Drive, and Settings.
- Added device profiling in `frontend/src/utils/deviceProfile.ts`, including iPhone/iPad detection and document-level `data-*` markers.
- Added responsive phone layout rules with a bottom tab bar, safe-area spacing, larger touch targets, and block-flow clone/design panels.
- Made public preview API calls use `/api` on non-loopback hosts so remote devices call back through the Vite proxy.
- Added `scripts/public-dev.mjs`, a watchdog runner for setup, backend, frontend, and Cloudflare quick tunnel.
- Kept the public-preview backend bound to `127.0.0.1`; Vite exposes the local UI and proxies `/api`.
